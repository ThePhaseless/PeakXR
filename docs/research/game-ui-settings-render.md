# PEAK 2.6.b: scenes, UI, settings, input, rendering, comfort (VR mod reference)

Audience: agents building the BepInEx VR mod. Unity 6000.3.15f1, Mono, URP 17, PUN 2.
Paths are relative to `decomp/` (`A/` = `Assembly-CSharp/`, `ZS/` = `Zorro.Settings.Runtime/`, `ZU/` = `Zorro.UI.Runtime/`, `ZC/` = `Zorro.ControllerSupport/`).

Provenance. Code facts come from `decomp/`. Scene, prefab, URP asset and Volume facts do NOT appear in the decomp. They were extracted from `PEAK_Data/data.unity3d` (a 1.5 GB UnityFS holding every level) with UnityPy 1.25 plus TypeTreeGeneratorAPI. They are marked `[data]`. Re-run on a game update. Scene to file mapping: `levelN` serialized file = build index N, `sharedassetsN.assets` = that scene's shared assets.

## 2. UI architecture

General: every canvas is authored in scenes/prefabs. **No runtime `new Canvas`/`renderMode =` in Assembly-CSharp** (grep clean), so a mod must modify canvases after they exist. All use `CanvasScaler` ScaleWithScreenSize [data]: HUD/Pause/BoardingPass/Names/Transitions/Letterbox/Hero reference 1920x1080 (MatchWidthOrHeight, match = 1.0 i.e. height); End/Passport reference 1280x720; CustomOptionWindow 1920x1080 (Expand mode); VersionCheck constant pixel size. When switching to World Space the scaler is ignored: set `RectTransform.sizeDelta = (1920,1080)` (or 1280x720), scale ~0.001 (1 px = 1 mm) and parent to a rig anchor.
`renderMode` enum values: 0 Overlay, 1 ScreenSpace-Camera, 2 WorldSpace.

### 4.3 Adding a VR tab and settings (code sketch)
Trick: `SettingsCategory` is an enum compared via `category.ToString()`. `((SettingsCategory)100).ToString()` == `"100"`, so a setting whose `GetCategory()` returns `"100"` shows under a cloned tab button whose `category = (SettingsCategory)100`. No enum patching needed.

```csharp
using Zorro.Settings; using Unity.Mathematics; using HarmonyLib; using UnityEngine; using TMPro;

static class VrTab { public const SettingsCategory Cat = (SettingsCategory)100; public static readonly string Key = ((int)Cat).ToString(); }

// 1) settings (PlayerPrefs key = type FullName, persistence is free)
namespace PeakXR.Settings {
  public class VrSnapTurn : CustomLocalizedOffOnSetting, IExposedSetting {          // bool-like
    public override void ApplyValue() { /* push to your VR config */ }
    protected override OffOnMode GetDefaultValue() => OffOnMode.ON;
    public override List<LocalizedString> GetLocalizedChoices() => null;             // required abstract; null => custom strings
    public string GetDisplayName() => "PEAKXR_SNAPTURN";                              // LocalizedText key
    public string GetCategory() => VrTab.Key;
  }
  public class VrTurnSpeed : FloatSetting, IExposedSetting {                          // slider + input field
    public override void ApplyValue() { }
    protected override float GetDefaultValue() => 90f;
    protected override float2 GetMinMaxValue() => new float2(15f, 360f);
    public string GetDisplayName() => "PEAKXR_TURNSPEED";
    public string GetCategory() => VrTab.Key;
  }
  public enum VrComfort { Off, Low, High }
  public class VrVignette : CustomLocalizedEnumSetting<VrComfort>, IExposedSetting {  // dropdown
    public override void ApplyValue() { }
    protected override VrComfort GetDefaultValue() => VrComfort.Low;
    public override List<LocalizedString> GetLocalizedChoices() => null;
    public override List<string> GetCustomLocalizedChoices() => new() { "Off", "Low", "High" }; // skip LocalizedText for choices
    public string GetDisplayName() => "PEAKXR_VIGNETTE";
    public string GetCategory() => VrTab.Key;
  }
}

// 2) register: SettingsHandler is a plain class built in GameHandler.Awake (A/GameHandler.cs L176)
[HarmonyPatch(typeof(SettingsHandler), MethodType.Constructor)]
static class Reg { static void Postfix(SettingsHandler __instance) {
  __instance.AddSetting(new PeakXR.Settings.VrSnapTurn());   // Load+Apply immediately
  __instance.AddSetting(new PeakXR.Settings.VrTurnSpeed());
  __instance.AddSetting(new PeakXR.Settings.VrVignette()); } }

// 3) localization keys (re-inject after every table rebuild)
[HarmonyPatch(typeof(LocalizedText), "LoadMainTable")] static class Loc { static void Postfix() {
  void Add(string id, string en) => LocalizedText.mainTable[id.ToUpperInvariant()] = Enumerable.Repeat(en, 15).ToList();
  Add("PEAKXR_SNAPTURN","Snap turning"); Add("PEAKXR_TURNSPEED","Turn speed"); Add("PEAKXR_VIGNETTE","Comfort vignette"); Add("PEAKXR_TAB","VR"); } }

// 4) tab button: clone one existing tab in each SharedSettingsMenu after TABS.Start has populated `buttons`
[HarmonyPatch(typeof(TABS<SettingsTABSButton>), "Start")] static class Tab { static void Postfix(TABS<SettingsTABSButton> __instance) {
  if (__instance is not SettingsTABS tabs || tabs.buttons.Any(b => b.category == VrTab.Cat)) return;
  var src = tabs.buttons[tabs.buttons.Count - 1];
  var clone = Object.Instantiate(src, src.transform.parent);         // listeners are code-added in TAB_Button.Start, so clone is safe
  clone.name = "VR"; clone.category = VrTab.Cat;
  var lt = clone.text.GetComponent<LocalizedText>(); if (lt) lt.SetIndex("PEAKXR_TAB"); else clone.text.text = "VR";
  tabs.AddButton(clone); } }   // tab order = hierarchy order; SelectRelative cycles through it
```
Notes: (a) both Title and Pause menus clone automatically (Harmony hits any `SettingsTABS.Start`). (b) `IConditionalSetting.ShouldShow()` (return `!PhotonNetwork.InRoom`) if a setting must not change in-run. (c) Anything reading `GetAllSettings()` also sees the VR settings, e.g. the Zorro debug UI page `"Settings"` (`new SettingsPage(settings, this)` L70). (d) The tab layout is a hierarchy layout group; if the strip overflows, shrink the clone's `LayoutElement`. (e) In VR the dropdown (`TMP_Dropdown`) popups are overlay-less children of the same canvas: OK once the settings canvas is World Space. (f) For a mod-side config file instead, still register the setting but make `ApplyValue` write BepInEx `ConfigEntry<T>`; keep PlayerPrefs as the store only if you want game-native persistence.

## 7. Camera behaviors that cause VR sickness (and how to fix)

Core design: the camera is NOT a child of the character. `MainCameraMovement.LateUpdate` (`A/MainCameraMovement.cs` L61, `[DefaultExecutionOrder(500)]`) overwrites `MainCamera` transform each frame, in this priority: god-cam (`isGodCam`) -> `CameraOverride` -> fully passed out spectator -> rocket spectator -> `CharacterCam()` L272.

## 8. Audio listener

- Exactly one `AudioListener` is active in gameplay: on root `MainCamera` in Title, Airport, `WilIsland`, `Level_N` [data]. `A/MainCamera.cs` Update L58: `AudioListener.volume = Lerp(volume, 1, 0.1*dt)` (used by fades), `AudioMixerUnifier` (`A/Peak.Settings/AudioMixerUnifier.cs`) is added on Awake.
- Cached reference: `CharacterVoiceHandler._audioListener = MainCamera.instance.GetComponent<AudioListener>()` (`A/CharacterVoiceHandler.cs` L143), used in L218 for distance (`Vector3.Distance(a, _audioListener.transform.position)`). If you move/disable that component or substitute a new listener, update this private field (Harmony `AccessTools.Field`) and avoid two active listeners.
- Distance gating also uses `MainCamera.instance.transform.position` (`A/SFX_Player.cs` L97, `ItemDatabase` L59, `Billboard`, `IsLookedAt`, `Interaction.DoInteractableRaycasts` L196-205 (origin = `MainCamera.instance.transform.position`, forward = `.forward`), `BingBongStatus`, `OrbThatMakesYouSleepy` ...). Keep `MainCamera.instance.transform` = HMD pose (or patch the ones that should use the hand).
- Other listener-bearing objects exist but are inactive until cutscenes: end-cutscene cameras (14+ per island scene), `Scout/CinematicTest/MainCamera` clones in prefabs. In `PrepareEndCutscene` `MainCamera` is disabled; the cutscene camera's listener takes over. In VR, either keep your listener on the HMD rig and disable the cutscene cameras' `AudioListener` (`GetComponentsInChildren<AudioListener>(true)` at `sceneLoaded`) or accept the audio source moving with the cutscene.
- Spatial audio: Unity built-in spatializer settings are not documented here; verify the project's Spatializer Plugin (ProjectSettings not in data.unity3d) and `AudioMixer` groups (`SingletonAsset<StaticReferences>.masterMixerGroup`, `SettingsHandler.OriginalMixer`). Photon Voice: `PhotonVoice.dll`, local mic `MicrophoneSetting`, `PushToTalkSetting`, `VoiceObscuranceFilter` (L55 checks `GameObject.Find("Airport")`).

## 9. Top patch points (Harmony) and VR risks

1. `SettingsHandler..ctor` Postfix: register VR settings (4.3). `TABS<SettingsTABSButton>.Start` Postfix: add VR tab. `LocalizedText.LoadMainTable` Postfix: inject keys.

4. `CameraQuad.LateUpdate` + `GUIManager.AddStatusFX` L836: stereo-correct / reduce screen VFX.

Risks (rank): (1) Overlay-only UI: nothing visible until converted. (2) Camera hard-wired to ragdoll head + shake + FOV; the single biggest sickness source. (3) Deferred renderer + TAA + STP upscaling + fullscreen/SCPE passes + `CameraQuad` mono-frustum VFX: stereo correctness and perf (deferred has no MSAA; aim to disable HBAO/EdgeDetection first). (4) `MainCamera.gameObject.SetActive(false)` in end cutscenes and spectator/god cams that take the camera; rig must survive. (5) Scheme detection: XR devices do not map to Keyboard&Mouse or Gamepad; use a virtual gamepad. (6) `Camera.main` / `MainCamera.instance` assumed to be the single gameplay camera everywhere (interaction rays, audio, mirror, grass); keep it the HMD camera. (7) Loading-screen/`Modal` canvases appear while HMD still active: black void + world panel. (8) `Time.timeScale = 0` in offline pause: XR still renders; UI uses unscaled time.
